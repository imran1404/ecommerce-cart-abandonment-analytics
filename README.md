
# E-Commerce Cart Abandonment & Conversion Funnel Analytics

## Overview
This project analyzes e-commerce customer behavior to identify shopping journey drop-offs, measure cart abandonment, and develop data-driven conversion optimization recommendations.

## Objectives
- Analyze the product-view, cart, and purchase funnel.
- Identify conversion patterns across products and categories.
- Segment customers using observed purchase history.
- Evaluate conversion differences across suitable cohorts.
- Present insights through a Power BI dashboard.

## Technology Stack
- Python, pandas, NumPy, SciPy
- PostgreSQL, SQLAlchemy, psycopg
- FastAPI
- Jupyter Notebook
- Power BI
- Git and GitHub

## Repository Structure
- `api/` — API application and tests
- `data/` — raw, processed, and analytical data
- `notebooks/` — Python analysis
- `sql/` — SQL scripts
- `powerbi/` — dashboard assets
- `docs/` — project documentation

## Dataset
Source: [Multi-Category E-Commerce Store Events](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store)

The exact downloaded files, date range, and sampling strategy will be documented after dataset validation.
